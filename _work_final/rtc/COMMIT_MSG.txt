fix(rtc): 音频半速解码修复 + seq 跨帧回绕修复

音频 (receiver.py, 来自另一分支的排查):
- libopus 即使单声道也返回交织格式 (1, 2N)
- 旧代码取 row 0, 把 2N 个样本当 N 个写入, 音频被拉长一倍
  (降八度且越来越慢)
- 改为按 layout 声道数去交织并下混, 长度不符时告警
- 验证: 90 秒传输, decoded_samples=4,319,040 = 89.98 秒, 精确吻合

seq 回绕 (sender.py SeqGen):
- 序号 16 位, 65535 后回绕; 原实现在帧中间回绕,
  65530 起的 10 个分片会跨过边界, 触发 'seq out of u16 range'
- 改为边界处留空洞, 不跨帧回绕 (重组靠 frame_id/chunk_idx, 空洞无害)
- 单元测试: 从 0xFFF0 起 200 次预留, 零溢出

90 秒实测:
- 视频 2694 帧, 0 丢失, 解码 2693, 解码异常 0
- 音频 4499 帧, 0 丢失, 解码异常 0
- A/V 偏移 p50=16.7ms p95=27.5ms max=46.7ms  (目前最佳)
